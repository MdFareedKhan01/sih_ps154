F7

Steps 1 and 2 run once per source. That is the whole reason the artefacts agree with each other: every generator reads the same canonical object, so severity, entity names and indicator values cannot drift between an advisory and a public post. keepKnownRefs is worth naming aloud — the model can invent a span id, and we drop any it invents rather than trusting it. Step 4 is the security boundary, and it is ordinary code: a classification check before an adapter is selected. The cloud adapter also throws EgressBlocked on restricted input as defence in depth, so a future refactor that breaks the router still cannot leak. Internal sources are masked by a placeholder map before they leave and restored when they return. Step 6 is the claim worth making slowly: verification is deterministic. Regular expressions and a hedge lexicon, not a second model asked to grade the first — because a model grading a model can be wrong in the same direction twice. Post-hoc citation matching is lexical term overlap, which is why this system needs no embeddings and no vector store: one source document fits in the context window, so there is nothing to search at scale. The repair arrow is the cap. revisionNote carries the exact findings back, and the ceiling of two calls per artefact is enforced in code and covered by a test that fails the build if a third call is ever made.
